# Clustered Eval Interval Simulations: datasheet

Simulated evaluation sets for a classifier with 18 classes, in which samples come in clusters (think prompts
answered by several authors), with the true balanced accuracy known. They come with the result tables of a benchmark
of confidence intervals for balanced accuracy. Everything is synthetic. Nothing comes from real people, texts or
classifiers.

## Provenance and generation

The data are generated by the code in
https://www.kaggle.com/code/locdunhat/confidence-intervals-for-clustered-eval-sets. The same package, `cmibench`, is
embedded in that notebook. Seeds are fixed (`SEED = 20261023`), so every file can be regenerated exactly.

- 18 classes with fixed difficulties: logits evenly spread from 0.3 − 1.5 to 0.3 + 1.5.
- Each cluster is answered by `m` classes: all 18, or `m` drawn without replacement.
- Whether a sample is classified correctly is Bernoulli with logit (class difficulty + cluster effect). The cluster
  effect is N(0, sigma²) and is shared by every sample of the cluster.
- The true balanced accuracy is computed by 64-point Gauss-Hermite quadrature.

## Files

| file | rows | content |
| --- | --- | --- |
| `eval_sets.csv` | 20 sets for each of 12 (sigma, m) pairs, 150 clusters each | `sigma`, `m`, `set_id`, `cluster`, `label` (class 0-17), `correct` (0/1), `true_balanced_accuracy` |
| `exp1_coverage.csv` | one row per set and method | `sigma`, `G` (clusters), `m`, `rep`, `method`, `lo`, `hi`, `covered`, `width` |
| `exp2_design_effect.csv` | 12 | `sigma`, `m`, `G`, `true_sd` (spread across 400 sets), `iid_se`, `cluster_se`, `iid_ratio`, `cluster_ratio` |
| `exp3_cv_vs_lb.csv` | 4 | `sigma`, `gap_sd`, `gap_q95`, `p_gap_ge_0_04` for CV (150 x 18) minus a 1,200-row public LB with 1-3 classes per cluster |

## Intended use

- Checking an interval method for clustered evaluation data against a known answer.
- Teaching: why a CV score on a train set where every prompt is answered by every class needs a cluster-robust
  standard error, and how much CV-vs-LB gap chance alone produces.

## Known limitations

- The cluster effect is the same for every class. Real prompts can be easy for some authors and hard for others.
- Correctness is simulated directly, with no features or classifier, so the sets say nothing about which model is
  better. They are only about the uncertainty of a score.
